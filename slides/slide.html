GitWorkflowDashboard

Real-time GitHub Actions Monitoring

Built with Rust • Single Binary • Zero Dependencies
1
The Problem

GitHub Actions at Scale is Overwhelming

  • Switching between repository tabs constantly
  • Losing track of which workflows are currently running
  • Missing failures until it's too late
  • No unified view across multiple repositories
2
The Solution

A Single Pane of Glass

GitWorkflowDashboard gives you a unified, real-time view of all your GitHub Actions workflows across every repository — in one browser tab.

Real-Time

WebSocket live updates & GitHub webhooks for instant state changes

Multi-Repo

Monitor workflows across dozens of repositories simultaneously

Single Binary

Ships as one executable — no Node.js, no frontend build step

3
Technology

Built Entirely in Rust

Embedded HTML frontend assembled at compile time. No Node.js, no separate frontend build, no external dependencies. Just run it and open your browser.

Backend

actix-web 4 • reqwest • tokio async • SQLite

Frontend

23 modular source files assembled by build.rs into a single embedded HTML

Deployment

Cargo • Docker • macOS DMG Installer

Testing

273 tests (62 lib + 106 binary + 105 integration)

4
Dashboard

Six Powerful Tabs

Active Runs

Live view of every in-progress workflow across all repos

Workflows

Searchable overview of all workflow definitions

Actions

Trigger dispatch runs with auto-discovered typed input forms

History

Completed runs with time-range filters and re-run

What's Happening

Activity overview with aggregate stats and timeline

Analytics

Success rates, duration trends, failure analysis, leaderboards

5
Orchestration

Pipeline Orchestration

Build custom pipeline tabs with sophisticated workflow orchestration, built right into the dashboard.

Numbered Stages

Sequential execution plan with parallel workflows within each stage

Approval Gates

Manual approval prompts between stages before proceeding

Slack Notifications

Template library with variable substitution at any pipeline point

Export / Import

Share pipeline configurations as JSON for team collaboration

6
Architecture

Under the Hood

Real-Time Updates

WebSocket broadcast + GitHub webhooks for instant state changes

Adaptive Polling

Exponential backoff with jitter respects your API rate limits

SQLite Persistence

Data survives restarts with WAL mode for concurrent reads

Security

Token auth, CSRF, rate limiting, CSP headers, XSS prevention
